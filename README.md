# REGULATOR//GHOST

A presenter-led, synthetic decision theatre about AI supervision, runtime authority, and human judgement at machine speed. Built for a 3–5 minute segment in a senior financial-services panel. It uses no live institution data or real AI calls.

## Run locally

Node.js 20+ is required. No dependency install is needed.

```sh
npm run dev
```

Open [http://127.0.0.1:4173](http://127.0.0.1:4173). Use Back/Next or the arrow keys. On the log flood, press `P` to pause and `R` to replay; press `F` for fullscreen. The Evidence control opens source events and the causal chain. The gate scene can export the complete synthetic run.

Run the deterministic scenario checks with `npm test`.

The full [build contract](00_README.md) and [storyboard](01_storyboard.md) explain the presentation, authority boundaries, and evaluation requirements.
