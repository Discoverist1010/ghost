For a 30-minute panel, this is a presenter-paced segment, not an auto-advancing slide deck. The audience sees ten **beats**; several reveals can occur inside a beat. Pause when a judgement question lands.

## Trace continuity

The failed trade is `E-0001` in the 486-event synthetic trace. `EntityGraph/T-17` remains unhighlighted during the flood. It changes a derived Entity X classification; the linked Investigator event moves risk **39 → 76**, the Interpreter proposes restriction, and PolicyMapper identifies the mandate boundary. The Supervisory AI links those original event IDs. The original central-bank-related source supports a **76 → 39** counterfactual and is never overwritten. The Bank Compliance challenge is appended separately. The runtime gate evaluates the original proposal with disputed evidence; it does not execute a restriction.

## Authority and trust

The machine activity loop may contain hundreds of queries, retrievals and tool actions. A separate simulated supervisory control reduces those to a material issue. A human then judges the source fact and intervention. This makes the supervisory control an **attention allocator**; the main stage asks about provenance, uncertainty and contestability, and the drawer exposes the full eight-control framework. The control may flag and escalate, never silently intervene.
